## Conventions de cette documentation

- **Langue** : français, droit français et européen d'abord. Les références portent leur date ; ce que la
  recherche n'a pas confirmé est marqué « à vérifier ».
- **Mise en forme** : lignes de 120 colonnes au plus, un titre `#` par fichier, tableaux plutôt que longues
  listes, chemins et commandes entre accents graves.
- **Liens** : relatifs et vérifiés. Un document ajouté ici entre dans la table ci-dessus ; un test du dépôt
  vérifie que cet index et le contenu du dossier concordent.
